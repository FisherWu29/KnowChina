# Architecture Decisions

Status: Active

Use this directory for Architecture Decision Records (ADRs).

## Filename Format

Use:

```text
YYYY-MM-DD-short-decision-title.md
```

Example:

```text
2026-05-16-use-cloudflare-workers-for-api.md
```

## ADR Template

```md
# Decision Title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context

What problem or constraint led to this decision?

## Decision

What did we choose?

## Consequences

What gets easier, harder, or riskier?

## Links

- Related code:
- Related docs:
```
