# UI Assets

Status: Active

Use this directory for design-facing visual assets.

## Suggested Structure

| Path | Purpose |
|------|---------|
| `icons/` | Source icons and exported icon sets |
| `images/` | Product imagery, illustrations, and generated visuals |
| `screenshots/` | App and website screenshots |
| `store/` | App Store and Google Play visual assets |

## AI Notes

- Prefer source files plus exported files when both exist.
- Include provenance notes for generated or third-party assets.
- Do not put runtime-only app assets here unless they are also design source material.
